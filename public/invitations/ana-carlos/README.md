# Recursos de Ana y Carlos

Demo ficticia con archivos propios por slug. Las fotos reutilizan otra selección de la colección Unsplash licenciada en fase 1, documentada en `docs/visual-assets.md`:

- `photos/main.webp`: recepción (CDN `photo-1519225421980-715cb0215aed`), ahora foto principal.
- `photos/ceremony.webp`: ramo blanco de Nicole Corbin (CDN `photo-1523454131402-131223cdd00e`).
- `photos/celebration.webp`: pastel (CDN `photo-1535254973040-607b474cb50d`).
- `ornaments/sprig.svg`: rama original del proyecto, copiada localmente para permitir una personalización independiente.
- `backgrounds/paper.svg`: textura SVG original de demostración.

Ninguna fotografía representa los lugares ni la pareja ficticios. Para un evento real, reemplazar por fotografías autorizadas y actualizar dimensiones/textos alternativos en la configuración.
